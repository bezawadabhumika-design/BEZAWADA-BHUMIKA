# Startup Funding Analysis Using Python

## Project Overview

This project analyzes startup funding data using Python to uncover investment trends, funding patterns, top-performing sectors, leading investors, and startup hubs. The analysis helps understand how startup investments have evolved over time through data visualization and exploratory data analysis (EDA).

## Objectives

* Analyze startup funding trends over the years.
* Identify the sectors receiving the highest investments.
* Find the most active investors.
* Compare startup funding across different cities.
* Generate meaningful insights using data visualization.

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Project Workflow

1. Import the dataset.
2. Clean and preprocess the data.
3. Perform Exploratory Data Analysis (EDA).
4. Visualize funding trends and investment patterns.
5. Generate insights and conclusions.

## Key Features

* Data cleaning and preprocessing.
* Funding trend analysis.
* Sector-wise investment analysis.
* City-wise startup analysis.
* Investor analysis.
* Interactive visualizations.
* Business insights for decision-making.

## Results

The analysis highlights the fastest-growing startup sectors, major investment hubs, leading investors, and funding trends, enabling data-driven business decisions.

## How to Run

1. Clone this repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
3. Open `Startup_Funding_Analysis.ipynb` in Jupyter Notebook.
4. Run all cells to reproduce the analysis.
